Na Chute, passei dois anos desenvolvendo sistemas de aprendizado de maquina em producao para analisar imagens compartilhadas online. Implementei o pipeline de machine learning de ponta a ponta e treinei modelos especializados de deep learning para reconhecer marcas, objetos e cenas.

Esses sistemas ajudavam empresas a identificar conteudo relevante e oportunidades de marketing em redes sociais em escala. Meu trabalho conectava o desenvolvimento dos modelos, o processamento de dados e a infraestrutura necessaria para executar a compreensao de imagens de forma confiavel em producao.

Tambem planejei e executei a migracao da infraestrutura de dados para uma arquitetura de streaming distribuida e tolerante a falhas, baseada em Apache Kafka. No dia a dia, trabalhei com o ecossistema de dados do Python, Redis, Caffe e NVIDIA DIGITS. Tambem avaliamos o TensorFlow conforme o framework surgiu.

O produto Chute Chat foi posteriormente adquirido por outra empresa.
